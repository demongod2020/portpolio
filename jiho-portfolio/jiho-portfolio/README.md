# Shin Jiho Portfolio

Next.js App Router 기반의 개인 포트폴리오 사이트입니다.

## Features
- Dark modern developer portfolio UI
- Responsive desktop / mobile layout
- IntersectionObserver scroll reveal animation
- Project card hover interactions
- Mouse-follow ambient glow
- Smooth anchor navigation
- Reduced-motion accessibility support

## Run locally
```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Production build
```bash
npm run build
npm start
```

## Customize
Main content is in `app/page.tsx` and styles are in `app/globals.css`.
Update project links, descriptions, and contact information there.
